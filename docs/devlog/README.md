## Guía de Formato

Todas las semanas se estructuran bajo el estándar oficial:
- **Objetivo:** Meta concreta de la semana.
- **Avance:** Tareas y laboratorios logrados.
- **Bloqueo:** Dificultades o errores conceptuales/técnicos.
- **Aprendizaje:** Conceptos clave asimilados.
- **Siguiente:** Próximo paso en el proyecto.
