# DevLog · Semana 02

## Objetivo
Comprender e implementar los fundamentos de autenticación y autorización en arquitecturas Cloud Native utilizando estándares OAuth 2.0 y OpenID Connect (OIDC).

## Avance
- Análisis de flujos de autenticación y autorización para la protección de microservicios.
- Creación y desarrollo del diagrama del flujo OAuth/OIDC en la herramienta Miro (`actividad_oauth_miro.md`).
- Identificación de roles principales: Resource Owner, Client, Authorization Server y Resource Server.

## Bloqueo
- Diferenciación clara entre los conceptos de Autenticación (quién es el usuario) y Autorización (qué permisos tiene el usuario) durante la modelación del flujo.

## Aprendizaje
- Comprender el estándar OAuth 2.0 para la delegación de acceso y cómo OpenID Connect agrega una capa de identidad sobre este para validar usuarios de forma segura.

## Siguiente
- Aplicar estos conceptos de seguridad en la configuración de API Gateways y protección de endpoints en los siguientes laboratorios.
